# Core Guidelines for Migrating TestGenie Extension to JIRA

- [ ] **UI Consistency**
  - [ ] Always use Material UI components to ensure the design matches the Azure DevOps extension.

- [ ] **Documentation Reference**
  - [ ] Before implementing any feature, use the Context7 MCP server to fetch and review the latest documentation and best practices.

- [ ] **Feature Limitations**
  - [ ] Identify features that cannot be implemented due to JIRA extension limitations.
  - [ ] Skip implementing these features.
  - [ ] At the end of the migration, provide a list of skipped features and the reasons for their omission.
